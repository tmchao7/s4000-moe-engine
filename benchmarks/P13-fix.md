# P13-fix — I33 修复(密桶 + pad 回退)验证(2026-10-30 夜)

- **背景**:P12 在线 A/B 判定段图 FAIL(并发 14–30 落桶间,TPOT p95 慢 5.9–14.7%),归因 I33 = 桶 padding 税。本报告验证修复:**①`NANOVLLM_SEGMENT_GRAPH_BUCKETS=dense`**(vLLM 式梯子 `[1,2,4]+range(8,64,8)` = 11 桶,pad 比 ≤1.41)与 **②`NANOVLLM_SEGMENT_GRAPH_PAD_RATIO=0.15`**(cap/bs > 1.15 时该 decode 步回退 eager,SGLang padding-即-eager 语义)。两开关默认惰性(不设=旧行为),生产默认不变。
- **冻结门(跑前写死于 `scripts/p13_fix_chain.py` 头注)**:
  - F1 SLO 不劣化:四档逐档,slo_standard 与 slo_strict 中位 fix ≥ eager − 1/128。
  - F2 无害化:1.0 档 TPOT p95 中位 fix ≤ eager × 1.02(P12 未修版 +5.9%;收回 ±2% 内 = 修复成立)。
  - F3 转正红利:1.0 档与 0.5 档 TPOT p95 均 ≤ eager × 0.97。
  - F1&F2 → 修复验证成立(段图成为惰性可选开关);F3 追加 → 开放转正讨论(今晚不翻默认)。
